# cec-1st-sem

## Ambulance traffic pre-clearance demo

A small C console app is included at `lday/ambulance_traffic_control.c`.
It helps plan when each traffic signal should be pre-cleared before the ambulance arrives.

### Build

```bash
gcc -std=c11 -Wall -Wextra -pedantic lday/ambulance_traffic_control.c -o lday/ambulance_traffic_control
```

### Run

```bash
./lday/ambulance_traffic_control
```
